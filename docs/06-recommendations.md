## 2. გაშვებიდან პირველ თვეში

- **SMTP ფოსტა** შეტყობინებებისთვის (ახლა მხოლოდ საიტზე ჩნდება). Microsoft 365-ის SMTP ან სხვა სერვისი.
- **ტელეფონზე ტესტი** ტექნიკოსებთან: მისვლა/დასრულება, ფოტოს ატვირთვა კამერიდან, რუკა. Home screen-ზე დამატება (PWA).
- **სამუშაო ფურცელი PDF**: კომპანიის ლოგო, რეკვიზიტები, ხელმოწერის ადგილი დასაზუსტებელია.
- **შეცდომების მონიტორინგი** (მაგ. Sentry) და ლოგები, რომ პრობლემა ჩვენამდე მოვიდეს კლიენტამდე ადრე.
- **1 გვერდიანი ინსტრუქცია** მენეჯერისთვის და ტექნიკოსისთვის.
- **ჩეკ-ლისტების შაბლონები** სისტემების მიხედვით (ხანძარი, CCTV, ელექტრო…) რეალური პრაქტიკიდან.

## 3. მოგვიანებით (თუ დასჭირდებათ)

- გაყიდვების მოდული: შეთავაზება → ხელშეკრულება → ინვოისი.
- საწყობი: მასალების ნაშთი და ჩამოწერა (ახლა მასალები მხოლოდ შეკვეთაზე იწერება).
- კლიენტის პორტალი: კლიენტი თავად ხედავს შეკვეთის სტატუსს.
- SMS შეტყობინებები ტექნიკოსებს.
- ბუღალტერიასთან ინტეგრაცია (მაგ. Excel ექსპორტი უკვე არის).

## 4. ტექნიკური შენიშვნები გუნდისთვის

- ტესტები მხოლოდ ლოგიკაზეა (vitest, 40 ტესტი); ბრაუზერული e2e ტესტები არ არის.
- Nominatim გეოკოდინგი უფასოა და ლიმიტიანია; ბევრი ობიექტის იმპორტისას კოორდინატები ხელით დაზუსტდება რუკაზე.
- DevApp-ის ბრაუზერის პანელი შრიფტს ადიდებს; დიზაინი ნამდვილ Chrome/Safari-ში შეამოწმეთ.
