# Line Net CRM — MVP სპეციფიკაცია (დადასტურებული 2026-09-16)

შეკვეთა შემოდის ელფოსტით → მენეჯერი აწესრიგებს და ანიშნებს შემსრულებელს → შემსრულებელი ასრულებს და სტატუსს ცვლის → ადმინი/მენეჯერი დაფაზე ხედავს სურათს.

## შეკვეთა (ცენტრალური ერთეული)
ველები: კლიენტი, ობიექტი/მისამართი, ტიპი (გამოძახება / პროექტი), აღწერა, ვადა, პრიორიტეტი, შემსრულებლები (ერთი ან რამდენიმე), ჯამური თანხა, გადახდის სტატუსი (გადახდილი / გადაუხდელი / ნაწილობრივ), დანართები, კომენტარები, ისტორია.

სტატუსები: ახალი → დანიშნული → მიმდინარე → შესრულებული → დახურული (+ გაუქმებული).

## ელფოსტის ინტეგრაცია (Microsoft 365)
- line-net.ge ელფოსტა Exchange Online-ზეა (დადასტურებულია MX ჩანაწერით).
- MVP: Outlook-ის წესი გადაამისამართებს წერილებს CRM-ის შემომავალ მისამართზე → CRM ქმნის შეკვეთას სტატუსით „ახალი“ გამგზავნით, თემით, ტექსტით, დანართებით.
- მენეჯერი ხსნის „შემოსულებს“, ავსებს კლიენტს/ობიექტს/ტიპს, ანიშნებს შემსრულებელს.
- მოგვიანებით: Microsoft Graph API პასუხის გასაგზავნად CRM-დან.
