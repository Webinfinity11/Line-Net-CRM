# ეტაპი 1.5 — სრულფასოვანი სისტემა (შეთანხმებული 2026-09-16)

MVP-ს ემატება. ყველა პუნქტი დადასტურებულია მომხმარებელთან კითხვა-პასუხით.

## შეკვეთა
- **სისტემა** (ველი): ხანძარსაწინააღმდეგო, ელექტრო, IT/ქსელი, პროექტირება, CCTV, წვდომის კონტროლი, განათება, კაბელტრასები, ავტომატიზაცია (BMS), სტრუქტურული კაბელირება, სხვა. ფილტრი, სტატისტიკა, შემსრულებლის შერჩევა.
- **დაგეგმილი დრო**: თარიღი + საათი. დღის განრიგი შემსრულებლების მიხედვით.
- **ობიექტზე დრო**: შემსრულებელი აჭერს „მივედი“ / „დავასრულე“. ინახება მისვლის და დასრულების დრო, ითვლება საათები და რეაგირების დრო.
- **მასალები**: მარტივი სია (დასახელება, რაოდენობა, ერთეული, თვითღირებულება). ჯამი = ხარჯი. თანხა − ხარჯი = მოგება. შემსრულებელი ხედავს სიას, ფასებს არა.
- **ჩეკ-ლისტი**: სისტემის მიხედვით შაბლონი (ადმინი აწყობს). შემსრულებელი პუნქტებს მონიშნავს. პერიოდულ შეკვეთას ავტომატურად მიებმება.
- **გარანტია**: თვეების რაოდენობა, ამოწურვის თარიღი. დაფაზე შეხსენება ამოწურვამდე 30 დღით ადრე.
- **სამუშაო ფურცელი PDF**: ამოსაბეჭდი ფორმა კლიენტის ხელმოწერისთვის: შეკვეთა, კლიენტი, ობიექტი, სამუშაო, მასალები, ჩეკ-ლისტი, დრო, ხელმოწერის ადგილი.

## შემსრულებელი
- **სპეციალიზაცია**: რომელ სისტემებს აკეთებს. დანიშვნისას შესაბამისი ხალხი წინ დგას.

## ობიექტი
- **აღჭურვილობის რეესტრი**: მოწყობილობა, მოდელი, რაოდენობა, სერიული, მონტაჟის თარიღი, გარანტია, რომელი შეკვეთიდან.

## რუკა
- ობიექტს აქვს კოორდინატები (მისამართიდან ავტომატურად ან რუკაზე დაწკაპუნებით).
- დაფაზე პატარა რუკა აქტიური შეკვეთების ობიექტებით, ფერი სტატუსის მიხედვით. ობიექტის და შეკვეთის ბარათზე რუკა მარკერით. OpenStreetMap, უფასო.

## პერიოდული ტექმომსახურება
- გრაფიკი: კლიენტი + ობიექტი + სისტემა + სიხშირე (კვირა, თვე, კვარტალი, ნახევარი წელი, წელი) + ნაგულისხმევი შემსრულებლები + თანხა.
- სისტემა ავტომატურად ქმნის შეკვეთას ვადამდე 7 დღით ადრე, ჩეკ-ლისტით. Cron ყოველდღე.

## შეტყობინებები
- სისტემაში (ზარი მენიუში, წაუკითხავის მრიცხველი) და ელფოსტით.
- შემსრულებელს: დაენიშნა შეკვეთა. მენეჯერს: შემსრულებელმა დაასრულა, ახალი წერილი შემოვიდა, ვადა გავიდა.

## პროფილი
- საკუთარი სახელი, ტელეფონი, პაროლის შეცვლა.

## ანგარიშები (ეკრანზე + Excel)
- კლიენტების მიხედვით: შეკვეთები, თანხა, გადაუხდელი.
- შემსრულებლების მიხედვით: შესრულებული, საათები, ვადაგადაცილება.
- სისტემების მიხედვით: შეკვეთები, შემოსავალი.
- თვის ფინანსური: შემოსული, ხარჯი (მასალები), მოგება, დებიტორები.
- Excel ექსპორტი ყველა ანგარიშზე და შეკვეთების სიაზე. კლიენტების იმპორტი Excel-დან.

## რიგითობა
1. სქემა + სისტემა + დრო + გარანტია + სპეციალიზაცია (ფორმა, ბარათი, ფილტრები)
2. ობიექტზე დრო, მასალები, ჩეკ-ლისტი (ბარათი, მობილური)
3. დღის განრიგი
4. აღჭურვილობა ობიექტზე
5. პერიოდული ტექმომსახურება + cron
6. შეტყობინებები + პროფილი
7. სამუშაო ფურცელი PDF
8. ანგარიშები + Excel
9. Microsoft ინტეგრაცია (Azure რეგისტრაციის შემდეგ)
